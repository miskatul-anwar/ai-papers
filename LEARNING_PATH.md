# Guided learning path

This is a route through representative papers. Read the [full timeline](TIMELINE.md) for every cataloged paper, or the [topic index](INDEX.md) to go deeper in one area. The year shown is the first publication or preprint year used in this library.

For each paper, write down its problem, core idea, evidence, limitations, and what later paper improved on it. Reproduce a small example when the method is algorithmic.
