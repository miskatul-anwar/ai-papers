About & Colophon

The AI Paper Library is an open research repository collecting 217 landmark papers in artificial intelligence, machine learning, neural networks, deep learning, NLP, knowledge graphs, neuro-symbolic AI, reinforcement learning, multimodal AI, LLMs, and autonomous agents spanning 1763 to 2026.

The catalog is designed as a reading curriculum rather than a claim of completeness. Every cataloged paper is preserved in full with a locally stored PDF, validated header and EOF markers, and cryptographic SHA-256 integrity checks.

Archival Statistics

  • Cataloged works: 217 papers
  • Verified PDFs: 217 (100% presence)
  • Total pages: 6,443 pages readable by pdfinfo
  • Total storage: 783 MiB
  • Temporal span: 1763 (Bayes) to 2026 (OSWorld 2 / Gemini / FlashNext)
  • Guided curriculum: 121 papers across 11 phases

Integrity & Verification

The library is audited with the bundled Python standard library script paper_library.py. The verification tool checks that every PDF is physically present, structurally sound, and matches its recorded SHA-256 hash in download_status.json: 

# Verify complete local archive integrity
python paper_library.py verify

# Check status of all catalog entries
python paper_library.py status

# Regenerate INDEX.md and TIMELINE.md from catalog.csv
python paper_library.py index

Catalog Schema

The primary data source is catalog.csv, formatted as follows:

  • id: Alphanumeric identifier used in paths and BibTeX keys.
  • year: First publication or preprint year used in the chronological reading timeline.
  • area: Category subdirectory within library/.
  • title: Official paper title.
  • authors: Publication authors.
  • source_url: Official publisher DOI resolver, ArXiv landing page, or project page.
  • pdf_url: Publicly accessible PDF copy source.
