About the AI Paper Library

The AI Paper Library is an open, curated collection of 217 influential research works in artificial intelligence, machine learning, neural networks, deep learning, natural language processing, knowledge graphs, neuro-symbolic AI, reinforcement learning, multimodal intelligence, large language models, and autonomous agents.

The archive covers over 260 years of intellectual development, from Thomas Bayes’ 1763 essay on probability to the frontier multimodal and autonomous reasoning agents of 2026.

Methodology & Integrity Checks

Every paper in this repository has been audited and verified locally using the included Python standard library tool paper_library.py. The verification script ensures:

  • The file exists in the designated area directory: library/<area>/<year>_<id>.pdf.
  • The file starts with the PDF magic header %PDF- and terminates with an %%EOF marker.
  • The file is non-empty and uncorrupted, successfully readable by standard PDF parsers (pdfinfo).
  • The file matches the recorded cryptographic SHA-256 checksum in download_status.json.

Running the Local Audit

You can audit or reproduce the library directly on any machine with Python 3.10+ (no third-party dependencies required): 

# Clone repository
git clone https://github.com/{{ site.repository }}.git
cd ai-papers

# Verify local archive integrity
python paper_library.py verify

# Check current status
python paper_library.py status

Catalog Structure

The repository catalog is stored in catalog.csv with the following schema:

  • id: Unique alphanumeric identifier (e.g. bayes1763, attention2017).
  • year: First publication or preprint year used in the reading timeline.
  • area: Category folder under library/ (e.g. 01_Foundations, 10_LLMs).
  • title: Official published paper title.
  • authors: Authors listed in publication order.
  • source_url: Official publisher page, DOI resolver, or ArXiv landing page.
  • pdf_url: Direct link to the open access PDF copy.

Hosted Site Architecture

This website is built with Jekyll and hosted on GitHub Pages. It features:

  • Client-side instant filtering & search: Sub-millisecond filtering across titles, authors, categories, and years.
  • In-browser PDF reader modal: Instant preview with full-screen and direct download capabilities.
  • One-click BibTeX export: Formatted academic citation export for every paper.
  • Reading progress tracker: Local storage progress persistence for the 121-paper guided curriculum.
  • Full responsive design: Optimized for mobile, tablet, and desktop viewports with dark and light themes.
